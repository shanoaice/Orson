# gc-anchor-allowlist.txt - reviewed exceptions for the GC anchor audit.
#
# Each line records one site where a mechanism IS claimed but its contract cannot be proven from
# the method's own IL. The validator proves the mechanism itself (GC.KeepAlive post-dominance,
# receiver liveness, a token-carrying construction, a delegated parameter); what it cannot see is
# the OWNERSHIP hop, because that is a property of the type graph and of the callers rather than of
# this method body. Every entry below is a human decision, and the reason states the invariant the
# decision rests on.
#
# Format:  <Type>[.<Member>] | <count> | <mechanism> | <why the site is safe>
#
# A TYPE-LEVEL entry (no member) records a TYPE-WIDE invariant and excuses NeedsReview verdicts for
# that whole type. It never excuses an Unsafe verdict: "nothing was claimed at all" is a different
# statement and must be named member by member, so a newly added unanchored member still fails the
# build instead of hiding behind its type.
#
# A stale entry - one that no longer matches any hazard site - also fails the build. Delete it.


AlpmSession.TryInitializeHandle | 2 | SafeAlpmHandle ownership | The raw handle returned by alpm_initialize is passed straight into new SafeAlpmHandle(ownsHandle: true); every managed call marshals through that SafeHandle, and SafeAlpmHandle.ReleaseHandle ends the native handle with alpm_release as a critical finalizer. Covers both the alpm_initialize call and the new SafeAlpmHandle construction.

AlpmCallbacks.ResolvePackageLifetime | 1 | delegated to caller | alpm_pkg_get_db is called during a synchronous question callback where the native handle and transaction/database are live on the native call stack. Resolves the unmanaged package pointer to the corresponding ChildLifetime.

AlpmCallbacks.DispatchEvent | 1 | delegated to caller | The event thunk passes the native union pointer directly from a synchronous libalpm callback frame; EventInvocation consumes it before DispatchEvent returns and stores no pointer.

AlpmCallbacks.DispatchFetch | 1 | delegated to caller | The fetch thunk passes both native strings directly from a synchronous libalpm callback frame; FetchInvocation decodes them before DispatchFetch returns and stores no pointer.

AlpmCallbacks.DispatchLog | 1 | delegated to caller | The log thunk passes the native format string and one-shot va_list directly from a synchronous libalpm callback frame; LogInvocation consumes both before DispatchLog returns.

InstallIgnorePackageQuestion | 2 | delegated to caller and token-carrying construction | Constructed during the question callback with a non-null ChildLifetime; the constructor copies package name and version out eagerly, and get_Package constructs a PackageView anchored to that lifetime token.

ReplacePackageQuestion | 5 | delegated to caller and token-carrying construction | Constructed during the question callback with non-null ChildLifetime tokens; the constructor copies old/new package names, versions, and new database name out eagerly, and get_OldPackage / get_NewPackage construct PackageViews anchored to those lifetime tokens.

PackageConflictQuestion | 4 | delegated to caller and token-carrying construction | Constructed during the question callback with non-null ChildLifetime tokens; the constructor copies package names, versions, and conflict reasons out eagerly from libalpm's conflict struct, and get_Package1 / get_Package2 construct PackageViews anchored to those lifetime tokens.

AlpmEvent | 19 | delegated to caller | FromUnion receives the event union by parameter and copies it out eagerly. Its only caller is AlpmCallbacks.EventAgent, which runs inside the libalpm call that owns the union. The PackageView values it builds are handed the callback's token so they stay readable exactly as long as the handle lives. The canonical stateless instances contain no native pointer and never escape the session's callback lifetime contract.

AlpmList`1 | 4 | receiver anchoring not modelled | ToArray reads the list through the Native accessor after Lifetime.ThrowIfStale(), and Enumerator.Current anchors the owning view with GC.KeepAlive(_list). The validator only recognises GC.KeepAlive(this), so an anchor on a field of this is invisible to it. The view owns no handle itself; the memory belongs to the list the caller borrowed it from.

AlpmStringList | 1 | delegated to caller | TakeOwned receives a libalpm list the caller has already disowned, materializes via NativeListMarshal.MaterializeAndFree for the duration of the copy, and frees it before returning. The anchoring obligation belongs to the call site that produced the list.

BackupEntry | 1 | delegated to caller | Factory(void*, Lifetime) receives the entry pointer as a parameter and copies the entry out. Every call site passes a pointer into a list owned by a view that is rooted on the caller's stack for the duration of the call.


Conflict | 4 | delegated to caller | Factory(void*) receives the conflict entry as a parameter and snapshots its names eagerly. The payload belongs to the caller's failure list and nothing is retained.

Database | 3 | token-carrying construction and delegated queries | Common database query methods and accessors either call GC.KeepAlive(this) or leave this live across the call, and Database.Lifetime is a non-nullable child of the handle's root token, so a live Database always roots the handle that owns backingStruct. The values it builds are handed that token, which is why the constructed-view sites read as Token ownership rather than Strong.

LocalDatabase | 1 | delegated to caller | Constructor delegates the native pointer and lifetime token to the Database base constructor; the local database pointer is owned by the session and managed via LocalDatabaseLifetime.

SyncDatabase | 7 | token-carrying construction and delegated Factory | Factory(void*, Lifetime) delegates its pointer parameter to the call site. Its accessors either call GC.KeepAlive(this) or leave this live across the call, and SyncDatabase.Lifetime is a non-nullable child of the handle's root token, so a live SyncDatabase always roots the handle that owns backingStruct. The values it builds are handed that token, which is why the constructed-view sites read as Token ownership rather than Strong.

MissingDependency | 1 | delegated to caller | Factory(void*) receives the entry as a parameter and copies the target and causing package names out eagerly. Nothing is retained beyond the strings.

Dependency | 1 | delegated to caller | Factory(void*, Lifetime) receives the dependency as a parameter and copies it out eagerly. Nothing native is retained.

FileConflict | 1 | delegated to caller | Factory(void*) receives the file-conflict entry as a parameter and copies its three strings out eagerly. Nothing is retained.

FileList | 1 | KeepAlive proven | get_Item calls GC.KeepAlive(this) before returning the materialised PackageFile. The file array is owned by the package and FileList.Lifetime is that package's token; the field is declared non-nullable LifetimeStamp.

Group | 5 | delegated Factory plus a parameter-owned call | Factory(void*, Lifetime) receives the group pointer as a parameter and copies the name and package list out. FindPackages anchors the dbs parameter - its Lifetime is read after the native call, which keeps dbs may-live across it - and only incidentally calls GC.KeepAlive(this) on a Group that owns no native memory.

LoadedPackage | 1 | owns the handle it is handed | The constructor takes the native pointer and its child lifetime token from Alpm.LoadPackage, which registers the pointer in the session registry for cleanup. The base constructor receives the pointer, and LoadedPackage.Dispose / Disown manage its lifecycle without a finalizer.

PackageFile | 1 | delegated to caller | Factory(void*) receives the file entry as a parameter. PackageFile is an eager snapshot struct that copies mode, size and name out and retains no pointer.

PackageVersion.CompareTo | 1 | owns no native memory | The type holds only a managed string. CompareTo marshals both operands into Utf8Buffer instances for the duration of alpm_pkg_vercmp, so no finalizer of this type could free what this call reads.
PackageView | 4 | delegated to caller | Factory(void*, Lifetime) receives the package pointer as a parameter. The constructor only stores the pointer and the token; it dereferences nothing, so the caller's view keeps both alive.

LoadedPackageRegistry.Unregister | 1 | delegated to caller | the native pointer is a method parameter: the anchoring obligation belongs to the call site
LoadedPackageRegistry.Dispose | 1 | receiver on stack | The registry holds the raw pointers and disposes them in a sweep when the owning AlpmSession is disposed before releasing the native handle.

AlpmSession.get_Version | 1 | static library call | alpm_version takes no handle and returns a static string pointer valid for the process lifetime.

AlpmSession.get_Capabilities | 1 | static library call | alpm_capabilities takes no handle and returns a bitmask of compile-time capabilities.

AlpmSession.ResolveDependency | 1 | token-carrying construction and database lookup | alpm_pkg_get_db and alpm_db_get_name resolve the owning database from the caller's databases, and the constructed PackageView receives that database's child lifetime token.

PackageChangelogStream | 2 | receiver on stack | PackageChangelogStream holds the owning PackageView instance, which roots the database or handle lifetime token for the package across changelog read and close operations.

MtreeEntry | 9 | delegated to caller | FromNative takes a borrowed pointer to an archive_entry and copies path, mode, size, mtime, uid, gid, symlink and digest out eagerly into a managed record.

PackageMtreeReader | 3 | receiver on stack | PackageMtreeReader holds the owning PackageView instance, which roots the database or handle lifetime token for the package across mtree read and close operations.
