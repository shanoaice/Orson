# Orson

> :construction: This is a work in progress.

Orson is a modern .NET binding and command-line interface for Arch Linux's libalpm, designed for high performance, type safety, and ergonomic package management.

## Subprojects

- [Orson.Alpm](./src/Orson.Alpm/README.md) is the C# FFI wrapper library for libalpm
- Orson.Alpm.FSharp (WIP) is a declarative F# library (based on Orson.Alpm) for libalpm
- Orson.CLI (WIP) is the feature-rich command-line interface and AUR helper built with Orson.Alpm
